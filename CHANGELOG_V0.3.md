# METROVERSE RP UE5 — v0.3 changelog

### Added
- Custom `AMetroversePlayerController` with server-routed chat RPCs.
- Eight roleplay chat channels and channel-specific send/receive authorization.
- Event/interview session scoping and read-only interview observer behavior.
- Same-city faction chat, cross-city Police Department chat, senior-staff restrictions and proximity-scoped Action chat.
- Message sanitisation, length cap, basic cooldown and bounded client-side chat history.
- City/session fields replicated in `AMetroversePlayerState`.
- Reprimand removal audit summary preserving details of the removed active record.

### Not claimed
This update does not add a finished game, realistic art assets, a playable city, complete UI, persistent accounts, a production server or a compiled build. Unreal compilation and multiplayer runtime tests remain outstanding.
